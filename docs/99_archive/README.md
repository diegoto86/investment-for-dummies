# Archive

**Status:** Non-Authoritative  
**Purpose:** Preserve obsolete or superseded project documents for historical reference.

---

# Rules

Files in this directory are **not active sources of truth**.

Use this folder for:

- previous Source of Truth versions;
- previous curriculum versions;
- deprecated methodology documents;
- superseded product requirements;
- retired technical plans;
- old experiments worth preserving.

---

# Naming Convention

Prefer names that make status obvious.

Examples:

```text
source_of_truth_v2_superseded.md
investment_bootcamp_curriculum_v1_superseded.md
old_product_architecture_2026-10.md
```

---

# Do Not

Do not:

- cite archived files as current requirements;
- ask Codex to treat archive content as authoritative;
- keep two active versions of the same canonical document;
- move uncertain documents here merely to avoid deciding which is canonical.

---

# Restoring Archived Content

If an old idea becomes relevant again:

1. review it against current canonical documents;
2. update it to current requirements;
3. create or update the correct active document;
4. do not simply move the old file back unchanged.
